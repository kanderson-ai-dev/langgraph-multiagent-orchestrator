# LangGraph Multi-Agent Orchestrator

> **Work in progress** — a Supervisor–Workers multi-agent microservice (FastAPI +
> LangGraph) for B2B report generation. A Supervisor dynamically routes work between a
> Researcher, a Writer, and a Reviewer/Auditor that debate until the report is
> approved — or escalate to a human.

Full documentation lands once the system is feature-complete.
